# 1VIEW

Releases of the 1VIEW TV app for Fire TV / Android TV. Source is kept separately.

Two editions, same app and same signing key, so either installs over the other and keeps your settings:

- `1VIEW-Browser.apk`: Web tab with an address bar only.
- `1VIEW-DeeTV.apk`: Web tab with the DeeTV shortcut.

## Install with Downloader

1. On the Fire TV Stick, install Downloader from the Amazon app store.
2. Settings → My Fire TV → Developer options → Install unknown apps → allow Downloader.
3. Open Downloader and enter the link of the edition you want from the latest release.
4. Install. Your profile, favourites and history are kept when updating.

## Updates

The app checks `version.json` in this repository in the background at launch and offers a newer build from Home or Settings → About. Leave Multi or playback before installing.
